# ReTempo（リテンポ）

動画の再生速度と音程を編集するWebアプリです。動画をサーバーへ送らず、ブラウザ内で読み込みから保存まで処理します。

## できること

- 12.5〜800%の速度変更。定規のドラッグ、数値入力、フレームレートの比率で指定
- 音程の保持、速度への連動、±24半音の独立調整
- 区間の分割・削除、トリミング、区間ごとの速度・音程・音量調整
- 縦横比を保つプレビュー、左右のダブルタップで10秒戻る・進む、コマ送り、区間ループ
- MP4・GIF保存。解像度、フレームレート、画質、音質を指定
- 編集設定の保存・読み込み、自動保存、元に戻す・やり直し
- 操作に重ならない点線の通知バーと通知履歴

## 使い方

1. 「動画を開く」でファイルを選びます。サンプルでも操作を試せます。
2. 速度と音程を調整します。動画の一部だけ変える場合は、再生位置を移動して「分割」を押し、編集する区間を選びます。
3. 再生して確認します。独立した音程や100%を超える音量は「音程込みで確認」で反映できます。確認用動画は選択区間から最大10秒です。
4. 「保存する」でMP4またはGIFを選び、「書き出しを開始」します。完了後に「ファイルを保存」を押します。

スマートフォンではプレビューの下にある「速度・音程」「区間・トリミング」で編集項目を切り替えます。左右のダブルタップは編集後の時間で10秒移動します。端では先頭・末尾まで移動します。

| キー | 操作 |
|---|---|
| Space | 再生・一時停止 |
| J / L | 10秒戻る・進む |
| ← / → | 1フレーム相当の移動 |
| S | 再生位置で分割 |
| Ctrl / ⌘ + Z | 元に戻す |
| Ctrl / ⌘ + Shift + Z | やり直し |

## 画質と音質

MP4の「映像をそのまま保持」は圧縮済み映像をコピーして表示時刻を変更します。映像の再圧縮は行いません。トリミング・区間削除のない、MP4対応映像で利用できます。

速度・音程・音量を変更していない対応音声も、条件を満たせば圧縮データをコピーします。音声の加工や画質指定では再圧縮が必要になり、完全な無劣化にはなりません。音程保持は音の高さを維持する機能です。

画質指定はH.264、加工音声はAACで保存します。初期値は画質優先・AAC 320kbpsです。AACは同梱のソフトウェアエンコーダーで保存するため、ブラウザのAACエンコード機能を必要としません。AAC保存に対応しないサンプリング周波数は48kHzへ変換し、通知します。音声を加工する場合は1〜8チャンネルに対応します。解像度を変更しても縦横比を維持します。H.264では偶数画素への丸めにより最大1画素程度の余白が生じることがあります。極端な速度・音程変更では音声に処理特有の響きが生じます。

GIFは最大256色で音声を含みません。主映像と主音声の各1トラックを扱い、字幕・追加音声・付加情報の完全保持には対応していません。HDRや透過を維持したい場合は映像コピーを使用してください。再圧縮時のHDR・透過保持、AIフレーム補間には対応していません。

## 対応環境

HTTPSまたはlocalhostで配信してください。ファイルを直接開く `file://` では動作しません。

MP4、MOV、WebM、MKV、MPEG-TSなどを読み込みます。利用できるコーデックはブラウザ・OS・端末によって異なります。「古い形式の動画を開く」では追加のFFmpegエンジンで互換MP4へ変換します。初回約32MBの取得が必要で、入力は128MBまでです。互換変換では再圧縮が発生します。DRMやすべての破損ファイルへの対応はありません。

通常の編集用データは初回取得後にキャッシュします。旧形式の互換変換には追加データが必要です。

iOSなどでWebCodecsの音声デコーダーが使えない場合、短い音声区間をWeb Audioで復号して処理します。音声の互換読み込みは自動です。動画全体をメモリに展開せず、映像はそのまま保持できます。端末自体が復号できないコーデックには互換変換が必要です。

書き出しはWeb Workerで実行し、対応環境では一時保存領域へ順次書き込みます。一時保存が利用できない場合、出力は128MBまでです。長い動画や高解像度の処理には十分な空き容量が必要です。Safari・iOSではバックグラウンド移動や画面ロックで処理が停止する場合があります。書き出し中は画面を開いたままにしてください。

## 配置・開発

Web配布用ZIP（`ReTempo-Web.zip`）を展開し、その中身をHTTPSの静的サーバーへ配置すると利用できます。ソース用ZIPには配信済みファイルを重複して同梱していません。JavaScriptはJavaScriptのMIMEタイプ、WASMは `application/wasm` で配信してください。

ソースから変更する場合はNode.js 22.18以降を使用します。

```sh
npm ci
npm run dev
```

配信用ファイルを作成します。

```sh
npm run build
npm run preview
```

出力先は `dist/` です。旧形式用エンジンも自分のサーバーで配信する場合は、ビルド前に `node scripts/fetch-compat.mjs` を実行します。追加するFFmpegビルドのライセンス条件も確認してください。
