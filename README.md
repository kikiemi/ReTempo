# ReTempo（リテンポ）

動画の再生速度と音程を変えられる、ブラウザで動く動画編集ツールです。

「少しだけ速くしたい」「声の高さは変えたくない」「この場面だけスローにしたい」といった編集ができます。動画をサーバーにアップロードせず、端末内で処理します。

スマホでも細かく調整できるように、速度と音程の操作には定規型のコントローラーを使っています。数値の直接入力もできます。

## できること

- 再生速度を％で指定
- 元と変換先のフレームレートから速度を計算
- 音程を保ったまま速度を変更
- 速度に合わせて音程も変更
- 速度とは別に音程を指定
- 動画の分割、区間ごとの速度設定、トリミング
- 音量の調整
- MP4・GIFでの書き出し
- 解像度、フレームレート、画質、音質の指定
- 編集設定の保存と読み込み

プレビューでは、コマ送りや区間ループ、元動画との比較ができます。画面の左右をダブルタップすると、10秒戻し・10秒送りになります。

## 使い方

1. 「動画を開く」からファイルを選びます。
2. 速度や音程を調整します。場面ごとに変えたい場合は「区間・トリミング」で分割します。
3. プレビューで確認して、「保存する」から書き出します。

ファイルを用意せずに触ってみたい場合は、サンプル動画も使えます。

## 画質・音質について

MP4の保存では、映像を再圧縮せずに再生時刻だけを変更する方法を選べます。対応する動画なら、映像の画質を保ったまま速度を変更できます。

解像度や画質を指定する場合は、映像を再圧縮します。音声も、速度や音程を加工する場合は再圧縮が必要です。すべての編集を完全に無劣化で行えるわけではありません。

GIFは最大256色で、音声は付きません。

## 対応形式

MP4・MOV・WebM・MKVなどの読み込みに対応しています。通常の読み込みで開けないファイルは、「古い形式の動画を開く」も試せます。

同じ拡張子でも、中に入っている映像・音声の形式によっては扱えないことがあります。読み込みや書き出しの対応範囲は、ブラウザや端末によっても変わります。

## 動かし方

### 配布用ファイルを使う場合

`ReTempo-Web.zip`を展開し、中身をWebサーバーに置いてください。GitHub Pagesなどの静的サイトでも動かせます。

HTMLファイルを直接開くのではなく、HTTPSまたはlocalhostでアクセスしてください。

### ソースから動かす場合

Node.jsとnpmを用意して、次のコマンドを実行します。

    npm ci
    npm run dev

配布用ファイルを作る場合はこちらです。

    npm run build

`dist`フォルダーに出力されます。

## 気をつけてほしいこと

大きな動画や長い動画の処理には時間がかかります。特にスマホでは、端末のメモリ不足で処理が止まることがあります。

書き出し中は、できるだけ画面を開いたままにしてください。別のアプリに切り替えたり、画面をロックしたりすると、ブラウザ側で処理が一時停止する場合があります。

元の動画ファイルは上書きしません。
